# iCloud Kontakte – Updates

Dieses Repository enthält nur die fertigen Windows-Installer der App **iCloud Kontakte**
und die Datei `latest.json`, über die installierte Apps neue Versionen finden.

Der Quellcode liegt in einem privaten Repository.

Jedes Update ist mit einem privaten Schlüssel signiert; die App installiert nur Updates
mit gültiger Signatur.
